# Проверка обещания СЕРВЕР, 11.10.2026

Пошаговый маршрут есть: требования VPS и регион, аренда VDSina/Timeweb, данные SSH, AmneziaVPN, проверка IP браузера и терминала, перенос проекта scp, ssh, официальный установщик Claude Code, проверка версии, вход, tmux, Remote Control, открытие с телефона и восстановление

Граница обещания: сервер не гарантирует отсутствие 403 и не возвращает отключённый аккаунт; это прямо сказано в zachem-server. Для самостоятельного VPN хватает 1 ГБ; для Claude Code статья требует 4 ГБ. Облако Anthropic вынесено в отдельный маршрут, не названо своим сервером

Пробелы для новичка, который поднимает всё с нуля:
- claude-code-na-servere начинается с переноса уже существующего проекта. Нет отдельного создания пустой папки проекта на VPS и маршрута без исходной папки на компьютере
- Первый вход ssh: не объяснены вопрос доверия новому host key и сверка fingerprint с провайдером
- Завершение маршрута показывает наличие сессии, но не даёт проверочной задачи с телефона и проверки изменения файла на VPS
