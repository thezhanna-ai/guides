## Три приёма целиком

Пары обозначают изменения запросов, а не проведённые испытания. Практика названа авторскими выводами из лекции. В обеих версиях каждой пары используются одинаковые материалы
### Приём 1. Явная инструкция об объёме и языке

Было:

```text
Объясни, как учится искусственный интеллект
```

Стало:

```text
Объясни, как учится искусственный интеллект, в двух коротких абзацах. Обычными словами, без формул. Возьми один пример из этого конспекта. Если информации в нём не хватает, скажи об этом и не добавляй неподтверждённые факты
```
### Приём 2. Краткое объяснение и отдельная проверка

Было:

```text
Скажи, какая из двух идей лучше решает мою задачу
```

Стало:

```text
Сравни две идеи для задачи, которую я опишу следующим сообщением. Кратко объясни решение по шагам: на какие мои условия опирается выбор и где не хватает данных. Затем проверь, не противоречит ли вывод условиям. В конце дай рекомендацию и назови её главный риск. Пока дождись задачи и двух идей
```
### Приём 3. Несколько попыток и отбор по условиям

Было:

```text
Предложи решение моей задачи
```

Стало:

```text
После моего следующего сообщения предложи три разных решения задачи. Проверь каждое по условиям, которые я укажу, и назови причину, по которой оно может не подойти. Не считай вариант проверенным только потому, что он звучит убедительно. Выбери подходящий и доработай его с учётом проверки. Если данных для выбора нет, задай один уточняющий вопрос. Пока дождись задачи и условий
```
Для первой пары вместе с каждым запросом вставляют текст конспекта. Для второй пары одинаковы задача и две идеи, для третьей задача и условия: обычный запрос отправляют вместе с ними, уточнённый сначала отдельно, затем материал следующим сообщением. В статье это описано прямо
