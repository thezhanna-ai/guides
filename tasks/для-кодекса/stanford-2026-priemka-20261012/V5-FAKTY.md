## Воспроизводимый подсчёт 401/64

Использован именно прежний метод по полному исходному содержимому txt, включая Markdown

```python
from pathlib import Path
import re
for name in ('1a', '1b'):
    text = (Path('tasks/для-кодекса/stanford-2026-priemka-20261012/PROGONY') / (name + '.txt')).read_text()
    print(name, len(re.sub(r'(?<=\w)[-\u2013](?=\w)', ' ', text).split()))
```

Вывод реального прогона:

```text
1a 401
1b 64
```

Граница метода: это количество разделённых пробелами элементов исходного Markdown, а не лингвистический подсчёт слов отображённого ответа. Например, отдельные `##`, `###`, `-`, элементы таблицы и кода входят в 401. Поэтому PASS здесь подтверждает именно заданный воспроизводимый метод, а не иную трактовку слова «слово». Метод в ходе этой инспекции не заменялся

## Расчёт сдачи через Decimal

```python
from decimal import Decimal as D
coffee = D(3) * D(285)
pastry = D(2) * D(190)
before = coffee + pastry
discount = before * D('0.15')
pay = before - discount
change = D(2000) - pay
```

Вывод реального прогона:

```text
coffee 855
pastry 380
before 1235
discount 185.25
pay 1049.75
change 950.25
change + pay 2000.00
pay / Decimal('0.85') 1235
(before - pastry) / Decimal(3) 285
pastry / Decimal(2) 190
```

Вывод: 950 рублей 25 копеек и все три обратные проверки арифметически верны
