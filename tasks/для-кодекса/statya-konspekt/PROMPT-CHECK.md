# Мысленный прогон пяти запросов по речи Джобса

Это проверка задания для модели, не описание сгенерированных картинок. Реальные результаты создаёт Жанна

| Запрос | Проверка на речи | Объём надписей |
|---|---|---|
| Карточки | 8-12 самостоятельных мыслей из трёх историй без новых событий | 8-12; при 12 карточках заголовок опускается |
| Комикс | По два кадра на историю; условный рассказчик объясняет мысли, не присваивает биографию | 6 реплик, не больше 8 подписей |
| Схема | Каллиграфия и Macintosh; увольнение и новая работа; ограниченное время и выбор пути | 3 × 3 + итог = 10 |
| Майнд-карта | Главная идея + три истории + две детали на каждую | 1 + 3 + 6 = 10 |
| Скетчноут | Три истории, короткие заметки, рисунки и финальная мысль | 1 + 3 × (1 + 2) + 1 = 11 |

На всех картинках до 7 слов в подписи, русский язык, светлый фон, стиль и формат. Имени автора в запросах нет. Предусмотрен путь для вставленного текста. Текстовые карточки - следующим сообщением
