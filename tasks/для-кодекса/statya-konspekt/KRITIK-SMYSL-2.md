# Проверка SMYSL, круг 2

Отдельный последовательный проход по извлечённому тексту статьи, без повторного чтения ТЗ.

Чисто. Боль: нет времени писать конспект и приходится перечитывать. Выгода: один текст для повторения, объяснения и связи мыслей. Запросы идут карточки → комикс → схема → майнд-карта → скетчноут. Петля тетради закрыта после помощи, перед рекламным блоком. Скетчноут последний. Не скрыто нужных действий ради интриги. Внутри пять комментариев результата, видимых заглушек нет.
