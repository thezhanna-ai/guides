# Проверяльщик MEKHANIKA - круг 1

Отдельный последовательный проход по извлечённому тексту article, без использования черновиков задания как текста статьи

Найдено: 3 служебных p в шапке без конечного знака (надзаголовок, уровень, дата). Они не повествовательные, но строгую командную проверку нужно очистить: оформить метки div. Основной авторский текст: длинные тире 0; Шаг 0 = 0; запрещённые слова 0; формы «ты ...л/ла/ли» 0. b=37, div.result=6, div.warn-card=2: выше образцов. Исходный CTA содержит 2 абзаца без точки и «Ивана»/«бесплатное»: оставляется побайтно по прямому ТЗ. Для article CTA вынести в штатную область рекламы после тела статьи; проверку всего HTML и исключение записать отдельно.
