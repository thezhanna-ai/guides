# Подготовка индексации pronovoe.com

Цель: автоматическая индексация из реестра без публикации

## Критерии приёмки

- Главная без запрета индексации (в исходном коммите запрета уже нет)
- Статья открыта только при status=live и отсутствии непустого noindex_reason
- H1/H2 из audits/2026-10-05-yurist.md остаются noindex, как gotova и draft
- Sitemap XML: главная и только разрешённые live, абсолютные https://pronovoe.com/, без вымышленных lastmod
- Генератор главной обновляет метатеги статей, sitemap.xml и robots.txt; --proverit проверяет всё без записи
- Новая live попадает при обычной сборке; смена статуса/причина запрета убирает URL из sitemap и возвращает noindex
- Текст страниц, оформление, партнёрские ссылки и правовые документы не меняются
- Все Python и Node тесты зелёные, коммит только в заданной ветке. Push, merge, браузеры, main, origin, Яндекс исключены
