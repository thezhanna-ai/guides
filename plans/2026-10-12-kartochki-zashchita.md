Подход: существующие unittest и HTML-парсер проекта, существующая проверка текстов генератора. Новых зависимостей не нужно. CSS получает явный общий размер 14.5px, ранее унаследованный от карточки

Риски: пустой обход карточек, разрешение 81 знака, пропуск черновиков, побочные изменения сборки. Проверки сравнивают число подписей с live-реестром, проверяют обе стороны границы и все статусы; diff ограничивает фактический состав изменений

Проверки: Python 3.14 выполнил 167 тестов, ошибок нет, три проверки изображений пропущены из-за отсутствия Pillow. Node выполнил 139 тестов без ошибок. --proverit: главная и 53 статьи совпадают с реестром. Восемь временных подмен подтверждают, что защита ловит 81 знак, inline style, лишний класс, вложенный тег, исчезнувшую подпись, повтор размера, отдельный селектор и сокращённое свойство font

Security-review: новые значения по-прежнему проходят существующее экранирование; проверка длины выполняется до записи файлов, включая черновики и --proverit. Новых зависимостей, сетевых обращений и операций с путями нет. Сравнение JSON подтверждает изменение только одного kratko; сравнение HTML подтверждает только сокращение этой подписи и общее правило размера
