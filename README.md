# Каталог гайдов

Один репозиторий для всех публичных раздаток и статей

## Постоянная структура

- `claude-ai/` - инструкции по Claude.ai
- `vaybkoding-claude/` - материалы по Claude Code
- `vaybkoding-codex/` - материалы по Codex
- `gpt-dlya-nachinayushchih/` - GPT для начинающих
- `gpt-dlya-prodolzhayushchih/` - GPT для продолжающих

Каждый материал хранится в собственной папке с `index.html` и получает отдельный URL. Главная страница отвечает только за каталог и переходы между категориями

## Сборка и индексация

После добавления статьи или изменения статуса в `data/statyi.json`:

```sh
python3 scripts/sobrat_glavnuyu.py --statya slug-stati
python3 scripts/sobrat_glavnuyu.py --proverit
python3 -m unittest discover -s tests -q
node --test tests/*.test.cjs
```

Сборка с `--statya SLUG` обновляет только выбранную статью и общие файлы каталога (главную, политику, sitemap, robots, llms). Файлы других статей, включая их assets, не перезаписываются. Без флага сборка обновляет только общие файлы. Для намеренного распространения общих шаблонов на все статьи нужен явный `--vse-stati`; не использовать его при работе над одной статьёй

В sitemap входят главная и статьи со `status: live`, у которых нет непустого `noindex_reason`. Остальные сохраняют `noindex, nofollow`. Проверка `--proverit` проверяет весь сайт без записи файлов; `--proverit --statya SLUG` ограничивает сравнение выбранной статьёй и общими файлами. Перед записью сборщик вычисляет результаты и проверяет SEO всего реестра, поэтому некорректная live-статья останавливает сборку до любых изменений

Шапка «Claude.ai: кнопка за кнопкой» сохраняется только у 12 раздаток рилзов 01-15 из `KNOPKA_01_15` в сборщике (02-04 и 13 используют одну статью). У остальных статей, включая новые со скопированной шапкой серии, сборка заменяет её на `<a class="brand" href="../../">Инструкции по нейросетям</a>`, как у ЧЕТЫРЕ. Категория каталога не определяет принадлежность к этим 15 рилзам

`noindex_reason` хранит причину запрета индексации, например высокий риск из юридического аудита. Изменение статуса на `live` не снимает этот запрет. Удалять причину следует после решения владельца и повторного аудита. Юридический аудит 05.10.2026: `audits/2026-10-05-yurist.md`

## Локальные шрифты

Все страницы и шаблон главной подключают `assets/fonts/fonts.css`. Шрифты WOFF2 находятся рядом: Spectral 300/400/600, Unbounded 700, JetBrains Mono 500/700. Кириллица и латиница сохранены, `font-display: swap` сохранён. Внешних подключений Google Fonts на страницах нет

`assets/fonts/manifest.json` содержит семейства, веса, версии, происхождение и SHA-256 каждого файла. Spectral 600 перенесён из локального HTTP-кэша без изменения байтов (кириллица, латиница, расширенная латиница). Остальные веса получены из локальных оригиналов с проверкой совпадения контуров, метрик и таблиц символов после преобразования в WOFF2. Лицензии OFL лежат рядом со шрифтами

Поручение владельца от 05.10.2026 выполнено для `shest-skillov` и `svoy-sayt-ne-bliznec`: формулировки практикума смягчены, причины запрета удалены из реестра. Обычная сборка включает обе страницы в sitemap. Исходный юридический аудит остаётся историческим документом до этих правок

## Политика данных и аналитика

Политика `/politika/` собирается из `scripts/shablon_politiki.html` тем же генератором. Общий `scripts/privacy-banner.html` добавляется на главную и все статьи из реестра, включая черновики. Ссылки в подвалах, локальный CSS/JS и URL политики в sitemap поддерживаются генератором. Файл подтверждения Яндекс Вебмастера не является страницей для посетителей и сохраняется без изменений

Номер счётчика задаётся только в `assets/privacy.js`, в константе `METRIKA_ID`. Сейчас значение пустое: ни скрипт, ни пиксель Метрики не загружаются. Чтобы включить аналитику после подготовки уведомления/инфраструктуры, указать реальный числовой ID в этом одном месте. Код из интерфейса Яндекса отдельно в HTML не вставлять: он обошёл бы согласие

Выбор «Принять» означает согласие на cookie и техническую статистику Яндекса, равноправная кнопка «Отказаться» сохраняет отказ. Настройки доступны из подвала; при отзыве работающего счётчика вызывается destruct и страница перезагружается. localStorage недоступен: сохранённое согласие не предполагается, явный выбор действует до закрытия страницы

Плашка фиксирована внизу, её измеренная высота резервируется для прокрутки подвала и фокусируемых элементов. При узком экране текст и кнопки переносятся; учтена безопасная область экрана. Плашка проверена в браузере на ширинах 390 и 1440 px, включая отказ, повторное открытие настроек и клавиатурный фокус

`tests/test_privacy.py` проверяет все страницы, sitemap, реквизиты и точки подключения; `tests/privacy.test.cjs` исполняет настоящий JS в Node VM с контролем загрузки скрипта, согласия, отказа, отзыва, storage-событий и ошибок localStorage. Это проверки без реальных запросов к Метрике, не захват сетевого трафика браузера

## Замена ERID перед публикацией

Маркировка целиком хранится статичным текстом в `p.ad-disclosure`: 45 статей, главная и `scripts/shablon_glavnoy.html`. JavaScript для ERID отсутствует. Шаблон участвует в замене, поэтому следующая сборка сохраняет токен

Из корня репозитория на macOS, с переменной `ERID`, содержащей настоящий токен из VK ОРД:

```sh
case "${ERID:?Сначала задай ERID токеном из VK ОРД}" in
  *[!A-Za-z0-9_-]*) printf '%s\n' 'Для этой команды ERID должен содержать только латинские буквы, цифры, _ и -' >&2; false ;;
  *) git grep -l -z -F 'ERID_PLACEHOLDER' -- '*.html' | xargs -0 sed -i '' "s/ERID_PLACEHOLDER/${ERID}/g" ;;
esac && python3 scripts/sobrat_glavnuyu.py --proverit
```

Ограничение ввода защищает статичный HTML и sed от специальных символов. Команда заменяет только `ERID_PLACEHOLDER` во всех отслеживаемых HTML-файлах, включая шаблон. Проверки `tests/test_erid.py` и `tests/erid.test.cjs` фиксируют состояние ветки с плейсхолдером до получения токена

## Поддержка SEO

Для каждой live-статьи нужна запись в `data/seo.json` с настоящим `lastmod`, title 20-65 знаков и исходное вступление 40-60 слов в HTML: это и есть быстрый ответ, отдельного абзаца перед ним нет
Штатная сборка добавляет canonical и JSON-LD и проверяет все требования до записи файлов; перед публикацией обязательны `--proverit`, Python и Node из раздела сборки выше, при ошибке публикация останавливается

`data/seo.json` хранит интент, рабочий запрос и метаданные; текст вступления хранится только в статье. `lastmod` меняется после значимой правки, а пересборка сохраняет дату. Canonical, JSON-LD из видимых H1/FAQ, хлебные крошки, тематические ссылки, robots, llms и даты sitemap обновляет тот же сборщик

После одобренной публикации: `python3 scripts/indexnow.py --send`. До неё запуск без аргументов только печатает payload. Отправка сверяет файл ключа и HTML всех URL payload с текущей рабочей копией; при несовпадении останавливается. IndexNow сообщает об изменении, но не гарантирует индексацию. Результаты аудита и ограничения находятся в `audits/seo-20261009/`

Первый экран главной использует локальные поднаборы тех же шрифтов, `assets/fonts/home-manifest.json` хранит их происхождение, SHA-256 и метрики замены Arial/Georgia. Исходные файлы шрифтов и начертания статей сохранены. Телефон получает обложку `hero-mobile.webp` размером 780x488, компьютер исходную 1600x1000; размеры резервируются в HTML, нужное изображение и шрифт заголовка загружаются заранее

## Предпросмотр статьи до согласования

Предпросмотр использует настоящий `claude-ai/SLUG/index.html` из текущего worktree, общие стили и локальные шрифты. Не копировать текст в упрощённую страницу с Georgia

```sh
node scripts/preview_article.cjs SLUG /tmp/article-preview
```

Нужны установленный Playwright и Google Chrome (по умолчанию `channel: 'chrome'`). Для существующей локальной установки можно задать `SITE_PLAYWRIGHT_MODULE` (путь к модулю), для отдельного Chromium `SITE_CHROMIUM` (путь к исполняемому файлу)

Если среда запрещает запуск Chromium, `SITE_CDP_URL=http://127.0.0.1:PORT` подключает уже запущенный локальный Chromium. Предпросмотр создаёт и закрывает только свои временные контексты, существующие страницы не использует. Удалённые CDP-адреса запрещены

Команда поднимает сервер только на `127.0.0.1` со случайным свободным портом и запускает отдельный временный профиль. Файлы сайта не записываются. До сохранения PNG 390x844 и 1440x1000 обязательны загрузка Spectral 300/400/600, Unbounded 700, JetBrains Mono 500/700, успешные ответы WOFF2, реальные семейства текста и заголовка, `lnum` тела и абзаца. Результаты сохраняются в `fonts.json`. При ошибке соответствующий снимок не создаётся, команда завершается с ненулевым кодом
