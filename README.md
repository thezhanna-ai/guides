# Каталог гайдов

Один репозиторий для всех публичных раздаток и статей

## Постоянная структура

- `claude-ai/` - инструкции по Claude.ai
- `vaybkoding-claude/` - материалы по Claude Code
- `vaybkoding-codex/` - материалы по Codex
- `gpt-dlya-nachinayushchih/` - GPT для начинающих
- `gpt-dlya-prodolzhayushchih/` - GPT для продолжающих

Каждый материал хранится в собственной папке с `index.html` и получает отдельный URL. Главная страница отвечает только за каталог и переходы между категориями

## Сборка и индексация

После добавления статьи или изменения статуса в `data/statyi.json`:

```sh
python3 scripts/sobrat_glavnuyu.py
python3 scripts/sobrat_glavnuyu.py --proverit
python3 -m unittest discover -s tests -q
node --test tests/*.test.cjs
```

Сборка обновляет главную, подписи обложек, метатеги robots статей, `sitemap.xml` и `robots.txt`. В sitemap входят главная и статьи со `status: live`, у которых нет непустого `noindex_reason`. Остальные сохраняют `noindex, nofollow`. Проверка `--proverit` обнаруживает расхождения без записи файлов

`noindex_reason` хранит причину запрета индексации, например высокий риск из юридического аудита. Изменение статуса на `live` не снимает этот запрет. Удалять причину следует после решения владельца и повторного аудита. Юридический аудит 05.10.2026: `audits/2026-10-05-yurist.md`

## Локальные шрифты

Все страницы и шаблон главной подключают `assets/fonts/fonts.css`. Шрифты WOFF2 находятся рядом: Spectral 300/400/600, Unbounded 700, JetBrains Mono 500/700. Кириллица и латиница сохранены, `font-display: swap` сохранён. Внешних подключений Google Fonts на страницах нет

`assets/fonts/manifest.json` содержит семейства, веса, версии, происхождение и SHA-256 каждого файла. Spectral 600 перенесён из локального HTTP-кэша без изменения байтов (кириллица, латиница, расширенная латиница). Остальные веса получены из локальных оригиналов с проверкой совпадения контуров, метрик и таблиц символов после преобразования в WOFF2. Лицензии OFL лежат рядом со шрифтами

Поручение владельца от 05.10.2026 выполнено для `shest-skillov` и `svoy-sayt-ne-bliznec`: формулировки практикума смягчены, причины запрета удалены из реестра. Обычная сборка включает обе страницы в sitemap. Исходный юридический аудит остаётся историческим документом до этих правок

## Политика данных и аналитика

Политика `/politika/` собирается из `scripts/shablon_politiki.html` тем же генератором. Общий `scripts/privacy-banner.html` добавляется на главную и все статьи из реестра, включая черновики. Ссылки в подвалах, локальный CSS/JS и URL политики в sitemap поддерживаются генератором. Файл подтверждения Яндекс Вебмастера не является страницей для посетителей и сохраняется без изменений

Номер счётчика задаётся только в `assets/privacy.js`, в константе `METRIKA_ID`. Сейчас значение пустое: ни скрипт, ни пиксель Метрики не загружаются. Чтобы включить аналитику после подготовки уведомления/инфраструктуры, указать реальный числовой ID в этом одном месте. Код из интерфейса Яндекса отдельно в HTML не вставлять: он обошёл бы согласие

Выбор «Понятно» означает согласие на cookie и техническую статистику Яндекса, «Без аналитики» сохраняет отказ. Настройки доступны из подвала; при отзыве работающего счётчика вызывается destruct и страница перезагружается. localStorage недоступен: сохранённое согласие не предполагается, явный выбор действует до закрытия страницы. Вебвизор/карта кликов/Яндекс Тег Менеджер выключены

Плашка фиксирована внизу, её измеренная высота резервируется для прокрутки подвала и фокусируемых элементов. При узком экране текст и кнопки переносятся; учтена безопасная область экрана. Браузерная проверка этой ветки не проводилась по заданию владельца

`tests/test_privacy.py` проверяет все страницы, sitemap, реквизиты и точки подключения; `tests/privacy.test.cjs` исполняет настоящий JS в Node VM с контролем загрузки скрипта, согласия, отказа, отзыва, storage-событий и ошибок localStorage. Это проверки без реальных запросов к Метрике, не захват сетевого трафика браузера
