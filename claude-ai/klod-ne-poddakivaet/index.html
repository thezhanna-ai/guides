Зачем нужен Frank

Frank - открытый скилл для ИИ-ассистента: набор инструкций, который убирает пустую похвалу и просит назвать главный риск. Он не проверяет факты за тебя, зато помогает увидеть возражение, которое иначе можно пропустить

Для следующих шагов нужен установленный Claude Code. Если его ещё нет, начни с инструкции установки Claude Code в VS Code. Если работаешь только в браузере, переходи к разделу «Если нет Claude Code»

1. Установи Frank в Claude Code

Открой в VS Code папку проекта, где работаешь с Claude Code, затем выбери в верхнем меню Terminal → New Terminal («Терминал» → «Создать терминал»). Командная строка откроется снизу в этой папке. Вставь команду и нажми Enter

В терминале
npx skills add huxleyli15/frank

Если появится вопрос о запуске пакета skills, введи y и нажми Enter. В установщике выбери навык frank и агент Claude Code. По умолчанию установка относится к текущей папке проекта, поэтому затем открой Claude Code в ней же. Дождись сообщения о завершении установки

Если нужен отдельный терминал: на Mac нажми Cmd+Пробел, набери «Терминал» и нажми Enter; на Windows открой «Пуск», набери PowerShell и запусти Windows PowerShell. Но для установки в нужную папку проще использовать терминал VS Code, как выше

Если появляется npx: command not found или сообщение, что npx не найден, установи Node.js версии LTS с официальной страницы, закрой и заново открой терминал, затем повтори команду

Необязательные подробности установки и исходник навыка есть в README Frank

Если устанавливаешь вручную, скопируй файл frank/SKILL.md из репозитория в папку ~/.claude/skills/frank/. Это путь из README для Claude Code; в итоге файл должен находиться по адресу ~/.claude/skills/frank/SKILL.md

Результат: Frank добавлен к навыкам Claude Code, теперь его можно вызвать в чате

2. Включи Frank

Открой чат Claude Code в той же папке проекта и отправь команду /frank. Без уточнения включается обычный режим full, который здесь называем «Прямой»

После команды задай свой вопрос как обычно. Frank меняет стиль разбора: сначала вывод и риск, затем аргументы и предложение, что сделать сильнее

Результат: Frank включён в режиме «Прямой»

3. Выбери степень прямоты

Режим меняется новой командой в чате. Ниже один и тот же запрос, чтобы было видно разницу. Ответы примерные, у тебя формулировки будут свои

Мягкий

/frank lite

Убирает лесть, сохраняет тёплый тон, отмечает один главный риск и помогает дальше

Ты пишешь

Хочу сделать сайт для всех

Клод отвечает

Можно. Только «для всех» никого не цепляет. Давай выберем группу людей и напишем первый экран под неё

Прямой · по умолчанию

/frank full

Начинает с вывода, признаёт сильную часть идеи, приводит возражение, держит позицию при споре и помечает, насколько уверен: [certain] (точно), [likely] (скорее всего), [guess] (догадка)

Ты пишешь

Хочу сделать сайт для всех

Клод отвечает

Сайт «для всех» плохо объясняет, кому он нужен [likely]. Ты хочешь охватить больше клиентов, и это разумная цель. Начни с одной группы и проверь, понимает ли она первый экран

Жёсткий

/frank ultra

Считает план слабым, пока он не выдержал вопросов. Сначала даёт сильнейшее возражение и просит доказательства

Ты пишешь

Хочу сделать сайт для всех

Клод отвечает

Это вывеска «всё для всех». Кто заплатит первым? Что он ищет? Почему уйдёт от того, у кого покупает сейчас? Нет ответа - рано делать сайт

Frank не обязан спорить ради спора. Если доводы хорошие, он может согласиться и назвать конкретную причину

Результат: ты знаешь, какую команду отправить, если нужна более мягкая или более строгая проверка

4. Выключи Frank

Напиши в чате stop frank или normal mode. До выключения выбранный уровень действует, пока ты его не поменяешь или не закончится сессия

Результат: Клод возвращается к обычной манере ответа

Если нет Claude Code

Обычному чату Claude или ChatGPT можно дать постоянную инструкцию. Скопируй запрос ниже и вставь в настройки. Это отдельный способ: команды /frank в браузерном чате для него не нужны

Готовый запрос
Работай как честный советник. В каждом ответе:
1. Не начинай с похвалы или автоматического согласия. Сразу переходи к выводу и главному риску
2. Разделяй подтверждённые факты, вероятные выводы и догадки. Если не знаешь, так и скажи
3. Не используй пустые фразы вроде «отличный вопрос» и «ты абсолютно прав»
4. Если не согласен, объясни причину, предложи альтернативу и назови риск моего подхода
5. Неприятный, но важный вывод ставь в начало ответа
6. Убирай вводные абзацы без пользы
7. Не меняй мнение только потому, что я настаиваю. Меняй его, когда появились новые доводы или данные
Не придумывай возражения, когда идея обоснованна. Будь прямым без грубости

В Claude: нажми на инициалы профиля слева внизу и открой Settings → Your Claude → Instructions. В прежнем интерфейсе этот пункт назывался Account → Instructions for Claude. Вставь текст и сохрани

В ChatGPT: открой Settings → Personalization → Custom Instructions, включи настройку и вставь текст в поле инструкций. Изменения применяются к чатам сразу

Если нужен советник только для одной задачи, вставь тот же текст обычным сообщением перед своим вопросом. В новом чате его придётся повторить. Чтобы отменить постоянную инструкцию, удали этот текст из настроек Claude или ChatGPT

Результат: инструкция сохранена для обычных чатов или действует в текущем разговоре, если вставлена сообщением

Проверь ответ на своей идее

После включения Frank или сохранения инструкции открой чат и отправь идею, в которой есть спорное место. Можно взять пример выше: «Хочу сделать сайт для всех». Посмотри, называет ли ответ конкретный риск, объясняет ли причину и предлагает ли следующий шаг

Для проверки постоянных настроек начни новый чат. Если правило осталось только в старом разговоре, вернись в настройки и проверь, сохранился ли там текст. Одно возражение ещё не доказывает, что совет верен: факты и выводы всё равно нужно проверять

Результат: вместо общей похвалы у тебя есть конкретное слабое место идеи и действие, которое поможет его проверить

Если Клод снова поддакивает

В длинном разговоре напомни о нужном разборе отдельным сообщением. Выбери запрос под свою ситуацию и отправь его в тот же чат Claude или ChatGPT

Найти слабые места
Найди три слабых места в моей идее. Для каждого объясни риск и предложи, как его проверить. Не придумывай возражения, если для них нет оснований
Проверить аргумент
Назови сильнейший контрдовод к моей позиции. Что я упускаю? Отдели факты от предположений и предложи более сильный вариант
Убрать пустую похвалу
Перепиши предыдущий ответ без пустой похвалы. Начни с главного риска и пометь, где факт, где вероятный вывод, а где догадка

Если ответ стал грубым, напомни: «Критикуй идею без оскорблений». Само несогласие не означает ошибку, но и резкий тон не делает вывод правильным. Попроси назвать доводы. В Claude Code можно также перейти на /frank lite

Памятка перед следующей задачей

  • В Claude Code установи Frank один раз в папку проекта, затем включай его командой /frank в нужном чате
  • Начни с full, выбери lite для мягкого тона или ultra для строгого разбора
  • В браузере сохрани готовую инструкцию в настройках или отправь её сообщением для одной задачи
  • Проверяй аргументы и метки уверенности. Для выключения Frank напиши stop frank

Частые вопросы

Скилл платный?

Frank опубликован с лицензией MIT и не содержит отдельного платного сервиса. Доступ к Claude Code и его лимиты зависят от твоего аккаунта

Он сломает обычные ответы?

Нет. Скилл задаёт манеру ответа в текущей сессии. Его можно выключить фразой stop frank или normal mode

Можно включить на одну задачу?

Да. Отправь /frank, задай вопрос, затем напиши stop frank

Почему Клод всё равно соглашается?

Frank не спорит с хорошо обоснованной идеей ради эффекта. Если согласие кажется необоснованным, попроси назвать сильнейший риск и доказательства

Если нужна помощь

Если запутался на установке или включении, отправь Клоду такой запрос. Замени текст в скобках своей ситуацией

Помощь по шагам
Хочу [включить Frank в Claude Code]. Сейчас вижу [сообщение или экран], уже выполнено [действия], непонятно [на каком месте остановился]. Объясняй по одному шагу и после каждого жди моего ответа
