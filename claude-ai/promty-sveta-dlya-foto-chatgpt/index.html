Как превратить команды света в рабочий словарь

Красивый свет иногда меняет лицо сильнее, чем кадр. Этот путь ловит подмену до публикации

ChatGPT не знает короткую команду заранее. Передай чату словарь, приложи исходник и вызови нужный свет одним словом

1. Приложи исходник

Открой ChatGPT, начни новый чат для /neonwash, добавь фотографию кнопкой вложения и дождись миниатюры

2. Отправь первый полный промпт

pink and blue neon

Скопируй плашку целиком, вставь под фотографией и отправь. Ниже этот промпт получит короткое имя /neonwash

Результат: чат создал первую картинку, которая позже будет вызываться командой /neonwash

3. Сравни результат с исходником

Открой исходник и результат рядом. Сравни форму носа и губ, разрез глаз, линию волос, одежду и предметы на фоне; отличается лишнее - повтори команду с исходным фото и перечисли, что сохранить. Выделение области для точечной правки описано в справке OpenAI по изображениям

Словарь для света, ракурса и камеры

Первый результат выше получен полным промптом без словаря. Этот блок загружает 17 коротких команд для темы «свет, ракурс и камеру»: в подтверждении должно стоять число 17. Карточку вида /имя - полный промпт ниже отправляй целиком вместе с фото; при первом запуске чат сохранит пару и сразу нарисует результат

Слеш-команды для картинок в этом чате:
1. Сообщение начинается с /команды из словаря: примени её промпт к моему фото и сразу рисуй, без вопросов.
2. Слова после команды добавляй к промпту.
3. Неизвестная команда записана как /имя - полный промпт: добавь эту пару в словарь, примени промпт к фото и сразу рисуй.
4. У неизвестной команды нет полного промпта после дефиса: ответь «Такой команды нет в словаре».
5. Сообщение «Добавь в словарь»: добавь команды, ответь «Добавлено: N, всего: M».
6. На это сообщение ответь: «Словарь принят, команд: N».

Проверка перед сохранением

Почему свет поменялся, а вместе с ним сдвинулись детали лица? Короткий промпт описывает желаемую картинку, но не закрепляет каждый участок снимка. В нашей пробе с садом это видно даже при слове only («только»). Начни с одного эффекта, открой исходник и результат крупнее, сравни лицо, волосы, одежду. Если они изменились, верни исходное фото и добавь, что нужно сохранить

Памятка на один экран

Перед новым вызовом /neonwash пройди эти пять строк по порядку

  • Сначала словарь, потом исходное фото и команда первой строкой
  • Новый ракурс проверяй по лицу, одежде и предметам на фоне
  • Каждый следующий эффект начинай с исходника, не с прошлой генерации
  • Для чистого кадра используй новый чат с тем же словарём
  • Если неон меняет лицо, допиши: «Сохрани форму носа, губ, разрез глаз и фактуру кожи; меняй только цвет света»

Частые вопросы

Почему /closeup не работает в пустом чате?

Короткое имя действует только там, где уже принят словарь с его полным промптом

Можно ли после команды уточнить цвет света?

Да. Напиши уточнение после команды, например: /neonwash холодный свет справа

Почему ракурс изменил одежду?

Генератор пересобирает весь кадр. Сравни результат с исходником и перечисли детали, которые нужно сохранить

Как сравнить несколько вариантов честно?

Для каждого варианта снова прикладывай исходное фото, чтобы изменения не накапливались
