Как команда ИИ-агентов готовит публикацию для блога

Средний уровень

Кто соберёт публикацию, если каждый агент делает свою часть?

Текст уже есть в одном чате. Картинка готова в другом. В третьем нашлись замечания, после которых нужно переписать вступление. Ты переносишь материалы, объясняешь, что изменилось, и следишь, чтобы в публикацию попала последняя версия.

Разберём учебный пример: нужно подготовить статью для блога. Проследим всю работу до момента, когда человеку можно показать результат. По пути станет понятно, какие поручения давать разным агентам и кто отвечает за то, чтобы они сложились в одну публикацию.

Что поручить команде

ИИ-агент здесь означает помощника, который может работать с файлами и выполнять действия через подключённые инструменты. Например, прочитать материалы проекта, сохранить текст статьи или проверить страницу сайта. Для каждой такой работы ему нужны соответствующие возможности и доступ к материалам.

Первое поручение звучит привычно: подготовить статью для блога. Но руководителю нужно понять, для кого она написана и что читатель должен получить. Статья для человека, который впервые открыл Claude Code, будет отличаться от материала для разработчика, выбирающего способ автоматизации.

В нашем примере блог объясняет начинающим работу с ИИ. Нужен материал о том, как передать помощнику расшифровку голосовой заметки и получить связный черновик поста. Это выбранная для объяснения тема, а не утверждение о проверенном поисковом спросе.

Если цель статьи состоит в привлечении людей из поиска, в задание добавляют отдельную работу: изучить реальные запросы и подходящие темы. Для неё нужен доступ к поиску или сервису статистики запросов. Красивое название статьи само по себе востребованность не подтверждает.

Так у руководителя появляется конкретное поручение: подготовить полезный материал для определённого читателя, используя подтверждённые сведения и правила блога. Теперь его можно распределять.

Кто распределяет работу

В схеме из карусели руководителем выступает Hermes Agent. Это отдельный ИИ-помощник, которому можно дать инструменты для работы и поручать запуск других агентов. В его официальном наборе есть инструкции для обращения к отдельным приложениям Claude Code и Codex. Оба исполнителя требуют собственной установки и настроенного входа. Подробности описаны в документации подключения Claude Code и документации подключения Codex.

Руководитель получает общую просьбу. Он определяет, какие материалы нужны, выдаёт поручения исполнителям и решает, можно ли принимать результат. Для примера распределим подготовку статьи так:

Участник Поручение Что возвращает
Hermes Уточнить цель материала, распределить работу, принять публикацию Собранный комплект с итогом проверки
Claude Code Подготовить текст по материалам и правилам блога Черновик статьи и использованные источники
Codex Проверить факты и страницу статьи, выполнить предусмотренные заданием проверки SEO Замечания с указанием места и причины
Помощник с инструментом генерации изображений Подготовить иллюстрацию по заданию к статье Изображение для публикации

Это возможное распределение для нашего примера. Его можно менять под доступные инструменты и задачу. Название приложения не закрепляет за ним профессию навсегда: Codex может готовить текст, а Claude Code проверять работу другого исполнителя.

ChatGPT, показанный в карусели, тоже может участвовать в отдельных поручениях. Для автоматической передачи работы требуется настроенное подключение. Открытая рядом вкладка с чатом сама по себе участником управляемой команды не становится.

Что передать вместе с поручением

Писателю нужны исходные материалы и правила. Если дать только тему, он будет сам выбирать аудиторию, тон и глубину объяснения. Проверяющему затем будет трудно определить, где ошибка, а где просто другой выбор автора.

Для нашего примера рядом с заданием сохраняют описание читателя, образец удачного поста и расшифровку заметки. Правила запрещают добавлять выдуманные события. В статье должны быть понятные действия, которые начинающий сможет повторить.

Поручение Claude Code получается предметным: прочитать расшифровку, собрать из неё связный текст, сохранить смысл автора и отметить места, где не хватает сведений. Если для статьи нужны сведения об интерфейсе, их проверяют по документации или реальному экрану.

Для новой публикации образец голоса и описание аудитории могут остаться прежними. Меняются тема и исходные материалы. У Hermes есть постоянная память между сессиями, но подробные материалы проекта стоит сохранять отдельно и давать к ним доступ. Устройство памяти описано в официальной документации Hermes.

Как результат попадает к следующему исполнителю

Claude Code сохраняет черновик в папку задачи. Руководитель передаёт Codex этот файл, исходные материалы и критерии проверки. Человеку не приходится пересказывать всю работу заново.

Критерии связаны с публикацией: факты подтверждены, примеры соответствуют инструкции, текст понятен начинающему. Если подготовлена страница сайта, добавляются проверки заголовков, описания страницы и ссылок. SEO, то есть подготовка страницы для поиска, здесь имеет конкретные пункты проверки. Это не обещание высоких позиций после одного запуска.

Codex сохраняет замечания отдельно. Например, в учебном тексте может появиться фраза, что помощник «помнит все прошлые разговоры». Проверяющий указывает, что такое утверждение слишком широкое, и просит уточнить, какие сведения сохранены и доступны помощнику.

Руководитель возвращает автору конкретное замечание. После исправления обновлённый текст снова проверяют. Отдельные файлы черновика и замечаний помогают различать версии и видеть, какие вопросы уже закрыты.

Передача через материалы задачи и приёмка по исходной просьбе разобраны также в гайде о мультиагентных системах. Здесь мы применяем эти принципы к учебной публикации; это не отчёт о проведённом запуске данной команды.

Кто принимает всю публикацию

К этому моменту текст может пройти проверку, а иллюстрация оказаться про другую тему. Или страница хорошо выглядеть на компьютере, но терять читаемость на телефоне. Общую работу принимает руководитель, сопоставляя её с первым поручением.

Он смотрит, получил ли начинающий обещанное объяснение. Совпадает ли иллюстрация с содержанием. Открываются ли ссылки. Учтены ли замечания к последней версии. Если поручили подготовить статью для сайта, одного текста в ответе недостаточно: нужна сама подготовленная страница.

Человеку возвращают комплект, который можно открыть и оценить: материал, иллюстрацию, страницу при необходимости и краткий итог проверки. Публикация в аккаунте или на сайте остаётся отдельным действием с нужным доступом и разрешением.

Так становится понятна работа руководителя. Он отвечает за всю просьбу, в том числе за то, что осталось между отдельными поручениями исполнителей.

Памятка для своей команды

Выбери одну повторяющуюся задачу и составь для неё короткую карточку. Можно начать с подготовки публикации, которую ты обычно собираешь из нескольких чатов.

Задача: подготовить публикацию для моего блога
Читатель: начинающий пользователь ИИ
Материалы: моя заметка, сведения о теме, образец удачного текста
Руководитель: распределяет поручения и принимает общий результат
Автор: готовит текст и отмечает недостающие сведения
Проверяющий: сверяет текст с материалами и правилами
Иллюстрация: готовится по содержанию принятого текста
Передача: материалы и результаты сохраняются в одной папке задачи
Готовность: текст и иллюстрация соответствуют поручению, замечания закрыты
Публикация: после моего разрешения

Сохрани карточку и дай её помощнику, который будет руководить работой. Попроси составить поручения исполнителям и указать, какие подключения нужны для их выполнения. Это даст тебе план своей команды до технической настройки.

В начале у нас были текст в одном чате, картинка в другом и замечания в третьем. Теперь у каждого материала есть место в общей задаче, а у публикации есть тот, кто доведёт её до приёмки.
