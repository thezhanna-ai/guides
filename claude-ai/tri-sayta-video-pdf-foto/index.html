Видео

Video2Frames: исходный ролик и готовая раскадровка

Video2Frames раскладывает видео на отдельные изображения. Это пригодится для обложки, карусели, раскадровки или одного точного момента из ролика.

  1. Открой сайт и нажми на поле выбора видео. Подходят MP4, MOV и WebM. После выбора над ползунком появилась длительность 57,4 секунды
  2. Переключись на Serial. Этот режим берёт кадры с одинаковым интервалом. Задай четыре секунды
  3. Нажми Start Serial Extraction. Сервис показал сообщение: извлечено 15 изображений
  4. Выбери формат. Export ZIP скачивает отдельные JPEG, Export PDF собирает их в один документ

Что получилось: ZIP с отдельными JPEG и PDF, где каждый кадр занимает свою страницу.

Документы

VectisPDF: документ до редактирования и после экспорта

VectisPDF открывает PDF в браузере. Там можно добавить или исправить текст, выделить фрагмент, удалить закрытые данные при экспорте, переставить страницы и объединить несколько документов.

  1. Нажми Select PDF. Выбранный документ откроется в редакторе
  2. Открой Viewer & Text и выбери Redact. Обведи фрагмент, который надо удалить. При экспорте сервис стирает эти данные из файла. Обычная чёрная плашка исходный текст не удаляет
  3. Задай имя и нажми Export PDF. Исправленный документ скачается со всеми страницами
  4. Для объединения открой Merge / Split. Добавь второй PDF и экспортируй общий файл на 26 страниц

Что получилось: исправленный PDF сохранил 12 страниц, а два документа объединились в один. Водяного знака в готовых файлах нет.

Фотографии

TimeStamp Camera: фотография та же, данных внутри уже нет

Внешне фотография не меняется, но внутри файла могут лежать дата, модель камеры и GPS-координаты. Раздел Photo Tools на сайте TimeStamp Camera сначала показывает эти поля, затем удаляет их перед публикацией.

  1. Открой EXIF viewer и выбери фотографию. Подходят JPEG, PNG, HEIC и TIFF
  2. Проверь Date & Time, Camera и GPS. Сервис покажет дату, модель телефона и координаты, если они записаны в файле
  3. Нажми Strip metadata instead. Откроется окно удаления данных
  4. Выбери фото и скачай очищенную копию. После обработки счётчик тегов должен обнулиться

Что получилось: в очищенной копии EXIF больше нет. Сервис убрал данные файла, а пиксели фотографии оставил на месте.

Где нужна осторожность: файл обрабатывается локально, но при показе названия места координаты отправляются картографическому сервису Nominatim. Если не хочется передавать координаты, не запрашивай подпись места и сразу переходи к очистке.

Сохранить

Памятка на один экран

  1. Картинки из видео: Video2Frames → Serial → интервал → Start Serial Extraction → Export ZIP
  2. Раскадровка одним файлом: Video2Frames → Export PDF
  3. Правка документа: VectisPDF → Viewer & Text → нужный инструмент → Export PDF
  4. Объединение документов: VectisPDF → Merge / Split → Add PDF → Export PDF
  5. Данные фотографии: TimeStamp Camera → EXIF viewer → Date & Time, Camera, GPS
  6. Очистка фотографии: Strip metadata instead → Choose photos → Download cleaned file

Самое полезное остаётся последним: кадр и PDF видны сразу, а координаты внутри фотографии никак себя не выдают.

FAQ

Частые вопросы

Нужно ли регистрироваться на этих сайтах?

Нет. Основные функции всех трёх сайтов открываются без аккаунта

Можно ли работать с телефона?

Video2Frames и TimeStamp Camera открываются на узком экране. VectisPDF при ширине 540 пикселей попросил перейти на компьютер.

Удаляет ли VectisPDF скрытый текст?

Режим Redact сообщает, что отмеченные данные удаляются из содержимого при экспорте. Это безопаснее, чем положить поверх текста чёрный прямоугольник.
