Улей агентов в Claude Code: Ruflo одной командой

Средний уровень

Когда Claude Code приходится и планировать, и писать код, и проверять себя, как раздать работу помощникам и не потерять общий контекст? Ruflo позволяет собрать такую команду внутри проекта.

Здесь всё происходит внутри Claude Code из терминала, без отдельной панели управления командой. Пройдём от настройки одной командой до небольшой страницы, которую исполнитель соберёт, а другой агент проверит. В последнем шаге проверим, что следующий чат получит требования и результат этой работы.

Ruflo, бывший Claude Flow, - программа на компьютере, которая помогает распределять задания между агентами и хранить сведения об их работе. Агент здесь - отдельный ИИ-помощник с порученной ролью. Координатор связывает части задачи и отдаёт замечания исполнителю. Это похоже на редакцию: один пишет, другой проверяет, редактор собирает окончательный вариант.

Улей лишний, когда нужно переименовать заголовок или исправить одну фразу: один агент обычно сделает это быстрее, чем команда распределит роли и обменяется результатами. Ruflo не снимает лимит Claude Code, а несколько исполнителей расходуют его на свою работу. Полезнее разделять задачу, где есть отдельные части и нужен независимый взгляд. Anthropic описывает, для какой работы подходят субагенты и какие у них ограничения.

Что нужно до начала

Нужен Claude Code, который запускается командой claude и отвечает после входа. Если есть только расширение в VS Code, проверь и терминальную команду: она устанавливается отдельно. Начать можно с инструкции по установке Claude Code. Доступ к моделям работает по условиям твоего аккаунта, Ruflo его не заменяет.

Также нужен Node.js версии 20 или выше и npm версии 9 или выше. Это требования Ruflo. Скачай Node.js с пометкой LTS («с долгой поддержкой») с официального сайта. Вместе с ним устанавливается npm, а npx позволяет запустить нужный пакет без отдельной глобальной установки.

Для первого опыта создай пустую папку ruflo-test и открой её в VS Code через File → Open Folder («Файл → Открыть папку»). Дальше выбери Terminal → New Terminal («Терминал → Новый терминал»). Терминал - нижняя панель, куда вводятся команды. Запускай их из этой папки, каждую отдельно, нажимая Enter:

node --version
npm --version
claude --version

Первые две команды должны вывести версии не ниже указанных, третья - версию Claude Code. Если видишь command not found («команда не найдена»), установи соответствующую программу, закрой терминал и открой новый. До появления трёх версий к настройке Ruflo не переходи.

Дальше подпись «В терминале» означает обычное окно команд. Подпись «В чат Claude Code» означает поле сообщения после запуска claude. Если уже находишься в этом чате, команда /exit возвращает в обычный терминал.

Шаг 1. Подготовь Ruflo одной командой

В терминале папки ruflo-test запусти короткую инициализацию из README Ruflo:

npx ruflo@latest init --no-global

Если npm спросит о загрузке пакета, проверь, что назван ruflo, введи y и нажми Enter. Дождись завершения команды. Флаг --no-global отключает добавление указателя Ruflo в общие инструкции Claude Code. Правила учебного проекта останутся в его папке. Здесь используется короткий вариант настройки, чтобы не выбирать параметры команды до первой задачи. Интерактивный вариант из того же README называется npx ruflo@latest init wizard.

Инициализация создаёт инструкции для Claude Code и служебные папки проекта. Среди них - CLAUDE.md с правилами работы и .claude-flow/ с настройками. Папки с точкой могут быть скрыты в файловом менеджере. Команда готовит инструменты; конкретная работа начнётся, когда ты отправишь задачу.

Результат: команда завершилась без ошибки, а в папке проекта появился CLAUDE.md с упоминанием Ruflo или Claude Flow. Дальше проверим, что Claude Code может обращаться к его инструментам.

Шаг 2. Проверь подключение MCP

MCP - способ подключить дополнительные инструменты к Claude Code. Через него Ruflo даёт доступ к координации и общей памяти. В терминале той же папки введи:

claude mcp list

Найди подключение claude-flow или ruflo и проверь, что рядом успешное соединение: Connected («Подключено»). Имя claude-flow осталось в команде текущего README, хотя пакет называется ruflo.

Если вместо соединения видишь Pending approval («Ожидает одобрения»), запусти claude из этой папки и одобри проектный сервер Ruflo, который только что настроили. Затем выйди через /exit и повтори claude mcp list. Так Claude Code разрешает подключения из настроек проекта.

Если ни одного из этих подключений нет, добавь сервер командой ниже и снова выполни claude mcp list. Флаг -y разрешает npx загрузить пакет без вопроса, на который фоновый сервер не сможет ответить:

claude mcp add claude-flow -- npx -y ruflo@latest mcp start

Если подключение уже есть, но не работает, второй сервер не добавляй. Причину разбираем в блоке «Если не получилось». Проверка списка серверов и команда /mcp описаны в справке Claude Code.

Результат: в списке есть Ruflo и подтверждено соединение. Одной записи с названием сервера недостаточно.

Шаг 3. Дай Claude Code обратиться к Ruflo

Теперь запусти Claude Code из того же терминала:

claude

Если появляется запрос доверия к папке или подключениям, прочитай его и подтверди только этот учебный проект. В чат Claude Code введи:

/mcp

Найди сервер Ruflo и его инструменты. Затем отправь в чат запрос:

Проверь подключённый MCP-сервер Ruflo: он может называться claude-flow или ruflo. Найди в его доступном списке инструменты координации и общей памяти. Выполни один доступный запрос чтения состояния или списка записей памяти, без создания агентов и файлов. Покажи название вызванного инструмента и его результат. Если вызов не прошёл, покажи точную ошибку. Не считай список инструментов доказательством успешного вызова.

Этот запрос проверяет связь действием. Пустой список памяти для нового проекта допустим: записей ещё нет. В руководстве Ruflo описана интеграция через MCP, а конкретные доступные инструменты смотри в своём подключении.

Результат: в чате виден успешный вызов инструмента Ruflo и его ответ. Теперь можно поручить ему координацию первой задачи.

Шаг 4. Собери страницу силами команды

Возьмём маленькую задачу, результат которой можно открыть: страницу с чек-листом подготовки короткого видео. Для неё не нужны внешние сервисы. Claude Code будет координатором, отдельный исполнитель напишет код, а проверяющий прочитает его и вернёт замечания.

Это существенное различие: Ruflo координирует работу, а Claude Code выполняет её. Вызов agent_spawn («зарегистрировать роль агента») сам по себе не доказывает, что отдельный исполнитель написал код. Для выполнения нужны субагенты Claude Code - отдельные помощники со своим заданием и контекстом.

Отправь в чат Claude Code весь запрос:

Собери в текущем учебном проекте локальную страницу demo/index.html «Готово ли видео к выпуску?». На ней шесть пунктов: понятный звук, читаемый текст, проверенные факты, права на музыку, правильный формат, просмотр целиком. У каждого пункта флажок. Показывай число отмеченных пунктов из шести и кнопку «Сбросить». Всё должно работать при открытии файла в браузере, без сети и установки библиотек.

Ты координатор. Используй подключённый Ruflo для координации и общей памяти. Сначала сохрани требования в demo/brief.md и в памяти Ruflo под ключом uley-demo-brief, в пространстве имён uley-demo. Пространство имён - общая группа записей для этой задачи. Проверь чтением, что запись сохранилась. Если память недоступна, остановись и покажи ошибку.

Дай отдельному субагенту Claude Code написать demo/index.html по этому заданию. После его завершения дай другому субагенту проверить файл по demo/brief.md: наличие шести пунктов, подсчёт, сброс, работу без внешних зависимостей. Перед каждой передачей задания достань требования из памяти Ruflo и передай их исполнителю. Регистрации ролей в Ruflo недостаточно: запусти настоящие задания субагентам Claude Code. Не допускай одновременного редактирования одного файла.

Пусть проверяющий сохранит замечания и выполненные проверки в demo/review.md. Верни замечания исполнителю, добейся исправлений и повторной проверки. Если браузер недоступен, отдели проверку кода от ручной проверки, не называй клики выполненными.

Сохрани итог в памяти Ruflo под ключом uley-demo-result, в том же пространстве uley-demo: что собрано, пути файлов, результаты проверок, что ещё требует ручного просмотра. Покажи успешные вызовы записи и чтения, роли, реальные задания субагентам и итоговый список файлов. В demo/README.md напиши, как открыть страницу и проверить её. Не подключай внешние API и ничего не публикуй.

После завершения найди demo/index.html в папке ruflo-test и открой двойным щелчком в файловом менеджере. Отметь любые два пункта: счётчик должен показать 2 из 6. Нажми «Сбросить»: все флажки снимаются, счётчик возвращается к 0 из 6. Если этого не произошло, верни Claude Code точное описание того, что видишь, и попроси исправить страницу с повторной проверкой.

Результат: страница открывается, счётчик и сброс работают. В чате видны отдельные задания исполнителю и проверяющему, в demo/review.md - проверки, а у Ruflo - успешные обращения к памяти. Теперь осталось выяснить, переживёт ли общий контекст новый чат.

Если не получилось

Инициализация завершилась ошибкой

В обычном терминале папки ruflo-test запусти диагностику Ruflo:

npx ruflo@latest doctor

Сохрани полный текст ошибки и результат диагностики. Отправь их Claude Code с просьбой объяснить причину и дать одно действие для исправления. Не повторяй установку с --force («принудительно»), пока не понятно, какие настройки она заменит.

Сервер есть в списке, но соединения нет

Выйди из Claude Code через /exit и снова проверь node --version в этом же терминале. Затем выполни npx ruflo@latest doctor. После исправления ошибки повтори claude mcp list, запусти claude и проверь /mcp. Разработчики рекомендуют начать с версии Node.js и регистрации сервера. До успешного вызова из шага 3 к командной задаче не переходи.

Claude пишет «команда создана», а файл делает сам

Попроси показать реальные задания субагентам Claude Code, их ответы и вызовы Ruflo. Если есть только регистрации ролей, верни запрос из шага 4 и попроси выполнить часть с запуском исполнителей. Отдельный ответ координатора со списком ролей ещё не даёт подтверждения командной работы.

Ruflo не возвращает сохранённое задание

Попроси проверить успешную запись ключа uley-demo-brief и прочитать именно этот ключ в пространстве uley-demo. Проверяй через тот же MCP-сервер, которым запись сохранялась: у другого подключения может быть другое хранилище. Ruflo поддерживает чтение по ключу и поиск, но пустой поиск не доказывает, что записи нет.

Шаг 5. Передай общий контекст новому чату

В текущем чате Claude Code введи /exit, затем снова запусти claude в той же папке ruflo-test. Отправь:

Через подключённый MCP-сервер Ruflo прочитай записи uley-demo-brief и uley-demo-result из пространства имён uley-demo. Сначала покажи успешные вызовы и содержимое записей, не подменяй их чтением файлов. Если запись не найдена, покажи ошибку и остановись.

По полученным записям объясни, какую страницу собирала команда, где лежит результат, какие проверки прошли и что осталось проверить вручную. Затем открой demo/brief.md и demo/review.md и сравни с памятью. Покажи расхождения. Пока не меняй файлы.

Вот как исполнители сохраняют общий контекст: координатор записывает требования в общую память, перед каждой передачей работы достаёт их и передаёт конкретному помощнику, а после проверки сохраняет итог. У субагентов свой контекст, поэтому не рассчитывай, что они автоматически знают весь разговор. Общая память полезна, когда команда действительно записывает и читает её.

Если новый чат вернул требования и итог через Ruflo, а файлы им соответствуют, у тебя есть весь рабочий круг: задание, отдельные исполнители, проверенный результат и контекст для продолжения. В следующем проекте этот же запрос можно заменить своей задачей, сохранив порядок передачи требований и проверки.

Результат: новый чат прочитал обе записи через Ruflo и назвал результат прошлой работы без пересказа с твоей стороны. Видно, что именно хранится в общей памяти и как это получает следующий исполнитель.

Запнулся? Спроси Claude. Попроси идти по одному действию

Ты

Хочу [желаемый результат] с Ruflo в Claude Code. Сейчас вижу [текущий экран или сообщение], уже выполнено [действия], непонятно [место затруднения]. Объясни по одному шагу и после каждого дождись моего ответа.

ClaudeУточни, на каком шаге остановились и что сейчас видно. Начнём с одного действия.
