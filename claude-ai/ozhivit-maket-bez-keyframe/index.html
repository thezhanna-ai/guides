Как оживить макет из Figma без ключевых кадров и получить Lottie-файл для сайта

Макет в Figma готов, а для сайта нужна анимация. Как понять, получится ли забрать из сервиса рабочий файл, а не только красивое превью? Пройдём от простого фрейма до скачанного Lottie и его воспроизведения на веб-странице

Доступные источники сверены 05.10.2026 · Маршрут по документации сервиса

Что Magic Animator делает с макетом

Карточка в Figma уже выглядит как надо, но движение приходится придумывать отдельно: когда появится заголовок, куда сдвинется фигура, как поведёт себя кнопка

Magic Animator от Lottielab - плагин, то есть дополнение внутри редактора Figma. Он предлагает готовые варианты движения для дизайна, а Animation Assistant принимает описание своей анимации словами. Это похоже на примерку: сначала смотришь варианты на одном макете, затем уточняешь, какой подходит

Lottie - формат анимации для сайтов и приложений. Файл JSON хранит её описание для специального проигрывателя. GIF и MP4 удобны для обычного просмотра, но это другие форматы. Ниже дойдём до проверки именно скачанного Lottie-файла

Граница инструмента: по документации Magic Animator правка ключевых кадров, то есть отдельных состояний движения, помечена Coming soon («Скоро»). Доступность Animation Assistant по тарифам и точное число ИИ-генераций на момент проверки не подтверждены. Экспорт редактора Lottielab проверяется отдельно: Lottie указан в Pro, GIF и MP4 доступны в Free

Начнём с одного фрейма в Figma. Так проще понять, что получилось, прежде чем переносить движение в большой макет

1. Подготовь простой фрейм и открой плагин

  1. Открой свой файл в Figma. Для первой попытки выбери фрейм, то есть отдельную область макета, с заголовком, простой фигурой и кнопкой. Оставь их отдельными элементами, чтобы легче видеть, что меняется
  2. Перейди на Magic Animator и нажми Get started («Начать»). По документации сервиса эта кнопка ведёт к плагину Figma. Если файл макета уже открыт, вернись в него и выбери Magic Animator в меню плагинов
  3. Открой плагин в Figma, выдели целиком нужный фрейм и передай его плагину. Перед генерацией сравни превью с макетом: на нём должны быть те же заголовок, фигура и кнопка

Результат: плагин показывает именно тот фрейм, который нужно оживить

Если не получилось: проверь выделение. Отдельная кнопка и весь фрейм - разные объекты. Выдели рамку нужного макета и снова открой плагин. Если страница сервиса недоступна, найди в Figma Community Magic Animator от Lottielab

Загрузка PNG/JPG из Canva и Adobe Express на момент проверки не подтверждена. Для этого маршрута оставайся в Figma. Следующий шаг покажет, какие движения уже можно примерить к макету

2. Нажми Generate animations и выбери движение

  1. В Magic Animator нажми Generate animations («Создать анимации»). Страница сервиса описывает эту кнопку как показ готовых вариантов анимации
  2. Проиграй доступные варианты. Смотри на заголовок и кнопку: текст должен оставаться читаемым, а движение помогать заметить нужный элемент
  3. Если доступен Animation Assistant («Ассистент анимации»), опиши одно желаемое движение, например: «Пусть круг плавно появляется, а заголовок остаётся на месте». Отправь запрос кнопкой со стрелкой в поле ассистента и снова проиграй результат. Если ассистента нет, продолжай с выбранным готовым вариантом

Результат: при воспроизведении макет движется, а его содержание остаётся понятным

Если не получилось: прочитай сообщение о задании и проверь доступный баланс в сервисе перед повторным нажатием. Точное списание кредитов не подтверждено, поэтому несколько одинаковых запросов подряд не помогут понять причину ошибки

Теперь нужно выяснить, что можно поправить в результате и как забрать его из сервиса

3. Проверь результат в редакторе Lottielab, если он доступен

Если интерфейс предлагает открыть результат в Lottielab, перейди в редактор и выбери один слой, то есть отдельный элемент макета. В Properties («Свойства») можно менять положение, размер и оформление слоя. Для первой проверки достаточно одного изменения, например размера фигуры, после которого снова проиграй анимацию

Результат: изменение относится к выбранному элементу, а остальной макет сохраняется

Если не получилось: когда доступен только готовый ролик, переход к слоям для этого результата не подтверждён. Пропусти необязательную правку и проверь доступные форматы в выгрузке Magic Animator на следующем шаге

Обычный редактор Lottielab имеет режим Animate («Анимация»), но его наличие не отменяет пометку Coming soon у правки ключевых кадров Magic Animator. Custom easing, собственная настройка ускорения движения, по документации ещё готовится к выпуску

Красивого превью пока недостаточно. На следующем шаге проверим, какой файл действительно можно скачать

4. Экспортируй Lottie JSON или доступный GIF/MP4

Если результат открылся в редакторе Lottielab, нажми Export («Экспорт») справа вверху. Дальше выбери формат по задаче

  1. Для сайта: открой вкладку Lottie (JSON), в блоке Lottie Embed options выбери Download Lottie, затем нажми Download («Скачать»). Эта последовательность описана в официальной инструкции экспорта
  2. Для обычного просмотра: выбери GIF или MP4 в панели экспорта. Эти форматы перечислены в документации выгрузки

Если редактор Lottielab недоступен, открой выгрузку самого Magic Animator и выбери один из доступных форматов MP4, GIF или Lottie. Точные надписи кнопок этой выгрузки на момент проверки не подтверждены. Если Lottie отсутствует, сохрани доступный ролик и не переходи к проверке JSON с этим файлом

Результат: на компьютере есть файл выбранного формата; для пути к Lottie это файл с расширением .json

Если не получилось: при закрытом экспорте Lottie проверь тариф. На странице Lottielab он относится к Pro, а GIF и MP4 доступны сразу в Free. Это условия редактора, они не подтверждают тарифы ИИ Magic Animator. У GIF/MP4 свой результат: ими можно посмотреть анимацию, но проверку Lottie ниже они не заменяют

Расширение .json само по себе ещё не доказывает, что анимация работает. Осталась проверка вне редактора

5. Проверь файл в официальном предпросмотре Lottie

  1. Открой Lottie Previewer от Lottielab. Регистрация для него не нужна
  2. Нажми Select file («Выбрать файл») и выбери скачанный JSON. Или перетащи этот файл в область Drag & drop («Перетащи сюда»)
  3. Сравни воспроизведение с выбранным вариантом: видно движение, заголовок и кнопка не пропали, порядок появления элементов сохранился

Результат: скачанный Lottie-файл проигрывается на официальной веб-странице, отдельно от редактора

Если не получилось: убедись, что выбран именно JSON из экспорта Lottie. Переименование видео в .json не меняет формат. Повтори экспорт по шагу 4. Если файл работает в Previewer, а на твоём сайте нет, дальше проверяется подключение проигрывателя сайта: официальный Lottielab Player предназначен для воспроизведения этих анимаций

Проверка закрывает весь путь: есть простой исходный макет, выбранное движение и файл, который работает вне сервиса. Previewer проверяет файл; воспроизведение на конкретном сайте нужно проверить после его подключения
