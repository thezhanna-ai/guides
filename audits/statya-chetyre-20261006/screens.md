# Живые скриншоты для Claude

В статье сейчас только обложка, скриншоты не подделаны и кадры исходного обзора не использованы

| Шаг | Какой кадр снять |
|---|---|
| Что нужно до начала | Терминал VS Code с claude mcp list: названия и статусы существующих серверов, без ключей и личных путей |
| 1. Perplexity | Список /mcp с perplexity и успешный поисковый вызов: версия, дата, официальный источник |
| 2. Playwright | Вызов открытия документации Next.js, заголовок и созданный файл скриншота; сам официальный документ в открытом браузере |
| 3. Firecrawl | Выбор firecrawl в /mcp и успешное авторизованное состояние; результат scrape с пояснением и примером со страницы |
| 4. Context7 | context7 в /mcp и вызов поиска библиотеки/документации: название, версия и ссылка |
| 5. Вместе | Итоговая таблица четырёх фактических вызовов и инструкция /about с указанной версией и официальным источником |

Не снимать ключи, заголовки Authorization, callback-адрес с токеном и кабинет с личными данными. Кадры обрезать до нужного элемента, вставлять через фигуры живой оболочки СКИЛЛЫ с «Открыть крупнее»
