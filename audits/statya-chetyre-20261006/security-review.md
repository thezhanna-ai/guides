# Security-review перед коммитом

Площадь проверки: новая страница и её assets, article.md, реестр статей/обложек, изменения трёх тестов, отчётные артефакты

- Секретов нет: в копируемых примерах только буквальное YOUR_API_KEY, читателю объяснено место замены и запрет показывать ключ

- На машине пользователя MCP не добавлялись и не удалялись; выполнены только справочные claude mcp add/remove --help
- В проверочных запросах запрещена отправка форм, общий запрос не меняет файлы проекта
- Новый index.html использует тот же JS, что живая статья СКИЛЛЫ; совпадение проверено побайтно, синтаксис проверен node --check
- Не добавлены внешние скрипты, аналитика, удалённые шрифты или пользовательский HTML
- Новая статья остаётся draft, net, noindex/nofollow и отсутствует на главной и в sitemap
- Изменения тестов добавляют конкретный черновик в состав; статус draft и отсутствие выдачи проверяются явно, прежние проверки ресурсов сохранены
- Общий реестр .business не перезаписан данными отдельной ветки. Скрипт штатной сборки запущен с BAZA_SAYTA и VYHOD этой ветки, Path.home перенаправлен только в вызове на /tmp/chetyre-registry-home для его дополнительной копии Desktop. Реестр ветки содержит одно слово ЧЕТЫРЕ
- Не изменены main, чужие ветки, существующие статьи и реальные настройки пользователя
