Что нужно до начала

Все подключения ниже делаем в Claude Code, помощнике для работы с папкой проекта. Обычный чат на сайте Claude.ai настраивается иначе. Если Claude Code ещё нет, начни со статьи «Claude Code и Codex в VS Code». Для команд понадобится и программа claude в терминале: если установлено только расширение VS Code, добавь её по официальной инструкции установки.

Открой папку проекта в VS Code. В меню Terminal → New Terminal («Терминал → Новый терминал») открой окно для команд. Вставляй команды по одной и нажимай Enter. Для проверки набери:

claude --version
node --version
npx --version

Каждая команда должна вывести номер версии. Node.js нужен для запуска Playwright MCP; разработчики требуют версию 18 или новее. Если команды node и npx не найдены, установи Node.js с пометкой LTS («с долгой поддержкой») с официального сайта, затем открой новый терминал.

Посмотри, какие MCP уже подключены:

claude mcp list

Если нужное имя уже есть, пропусти его установку и перейди к проверке в соответствующем шаге. Параметр --scope user в наших командах делает подключение доступным тебе во всех проектах, а не только в этой папке. Настройки сохраняются в личном файле ~/.claude.json, как описано в справке Anthropic.

Команды с claude mcp add вводятся в терминале, а просьбы помощнику и /mcp - внутри Claude Code. Для этих проверок запускай его командой claude в терминале той же папки. Чтобы добавить следующий сервер, закончи сеанс командой /exit, введи команду подключения и снова запусти claude.

Ключ API - секрет для доступа к сервису. В командах ниже вместо YOUR_API_KEY вставляется твой настоящий ключ. Меняй только эти слова, оставляй кавычки и пробел после Bearer. Делай замену в терминале на своём компьютере, не в чате помощника. Не показывай ключ на скринах, в переписке и в файлах, которые отправляешь другим. Если ключ уже виден посторонним, отзови его в кабинете сервиса и создай новый.

Для выбранного подключения Perplexity понадобится ключ API; для Firecrawl используем вход через аккаунт, для Context7 - ключ из его кабинета. Условия вызовов и остаток лимита смотри в каждом сервисе: подключение к Claude Code не отменяет его ограничения.

В Codex эти же серверы тоже подключаются, но команды и файл настроек другие; ниже весь маршрут относится к Claude Code.

Шаг 1. Perplexity: найди источник свежего ответа

Ты спрашиваешь, что изменилось в программе, а Claude Code отвечает без даты и ссылки. Проверять ответ приходится вручную. Perplexity MCP подключает к помощнику веб-поиск Perplexity: Claude Code отправляет поисковый запрос и получает найденные страницы. Сервис работает удалённо, на серверах Perplexity. Его назначение и инструменты описаны в официальном README.

Это похоже на помощника, который приносит тебе адреса нужных документов. Найденная ссылка ещё не означает, что документ подходит: дата и первоисточник требуют внимания. Для технических вопросов проси официальную документацию или страницу выпуска, а не случайный пересказ.

Открой кабинет Perplexity API, войди и создай ключ API. Путь к этому кабинету указан в инструкции сервера. Скопируй ключ, вернись в терминал VS Code и подставь его вместо YOUR_API_KEY:

claude mcp add --scope user --transport http perplexity https://api.perplexity.ai/mcp --header "Authorization: Bearer YOUR_API_KEY"

Это удалённое подключение с заголовком авторизации из README Perplexity. После сообщения Added («Добавлено») запусти claude, введи /mcp и найди perplexity. Затем отправь помощнику:

Через Perplexity найди последний стабильный выпуск Next.js на официальном сайте или в официальном GitHub vercel/next.js. Покажи номер версии, дату выпуска и ссылку на первоисточник. Не выбирай canary (тестовую сборку) или предварительный выпуск. Назови вызванный инструмент Perplexity.

Next.js - инструмент для создания сайтов; здесь он нужен только как общий пример, ставить его для проверки MCP не нужно. В следующих запросах встретится App Router - способ организации страниц в Next.js: их адреса задаются папками и файлами. Это объясняется в документации Next.js. Сохрани ответ Perplexity, версия пригодится в последнем шаге.

Результат: в чате виден вызов инструмента Perplexity, а в ответе есть версия, дата и официальный источник. Теперь найденную страницу можно открыть и увидеть.

Шаг 2. Playwright: открой страницу глазами помощника

Адрес сайта уже есть, но тебе нужно увидеть страницу и проверить, что на ней написано. Playwright MCP запускает браузер на твоём компьютере и даёт Claude Code команды для работы с ним. Помощник читает структуру страницы, может нажимать кнопки и сохранять скриншоты. Механизм описан в README Microsoft.

Это как дать помощнику место за соседним компьютером: он открывает сайт и показывает, что увидел. Для сайтов с авторизацией по-прежнему нужен вход, а ограничения доступа самого сайта остаются. Подключение не обещает доступ к любой странице.

Выйди из сеанса Claude Code через /exit и введи в терминале:

claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest

Пакет взят из README Playwright MCP. Разделитель -- передаёт оставшуюся команду программе запуска, это синтаксис Claude Code. Ключ API для этого подключения не нужен.

Снова запусти claude, открой /mcp и найди playwright. Отправь:

Через Playwright открой https://nextjs.org/docs/app/getting-started/layouts-and-pages. Покажи фактический адрес после открытия, заголовок страницы и сохрани скриншот в папке проекта. Назови файл скриншота. Ничего не отправляй через формы.

Открой сохранённый файл в VS Code и сравни его с заголовком в ответе. Если сервер сообщает, что браузер не установлен, попроси Claude Code выполнить предусмотренную сервером установку браузера, затем повтори проверку. Точную ошибку можно передать через блок помощи ниже.

Playwright MCP и Playwright CLI - два способа управлять браузером; установленный CLI не заменяет запись MCP в этом списке. Их различие поясняется в README Microsoft.

Результат: виден вызов Playwright, в ответе есть открытый адрес и заголовок, а файл скриншота существует и открывается. Следующий инструмент поможет взять со страницы содержимое для разбора.

Шаг 3. Firecrawl: прочитай страницу целиком

На скриншоте видна часть страницы, а для ответа нужны все её пояснения и примеры. Firecrawl MCP передаёт Claude Code содержимое страниц через удалённый сервис Firecrawl. Команда scrape читает один адрес, map ищет адреса внутри сайта, crawl собирает содержимое нескольких страниц. Это описано в официальном README.

Это похоже на читателя, который убирает меню и украшения и приносит тебе текст. Firecrawl также поддерживает действия на страницах, но для этой проверки используем чтение, а браузер оставляем Playwright. Закрытые страницы и ограничения доступа не исчезают. Перенос дизайна сайта он тоже не обещает.

Для полного набора подключим Firecrawl через аккаунт. В терминале после /exit введи:

claude mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth

Адрес взят из README, а команду для Claude Code даёт официальная инструкция Firecrawl. Этот адрес не надо открывать как обычный сайт.

Запусти claude, введи /mcp, выбери firecrawl и пройди предложенный вход в браузере. Если аккаунта нет, создай его в ходе входа. Подтверди подключение аккаунта, вернись в Claude Code и отправь:

Через Firecrawl прочитай https://nextjs.org/docs/app/getting-started/layouts-and-pages инструментом scrape. Верни заголовок, ссылку и объяснение из страницы о том, какой файл создаёт страницу сайта. Покажи один пример из документации. Не запускай crawl всего сайта.
Если нужен ключ API вместо входа через аккаунт

Выбери этот путь только вместо основного. Создай ключ в кабинете Firecrawl. Если запись firecrawl уже существует, сначала удали только её командой claude mcp remove --scope user firecrawl. Вместо YOUR_API_KEY вставь ключ в терминале:

claude mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp --header "Authorization: Bearer YOUR_API_KEY"

Адрес и заголовок авторизации указаны в README Firecrawl. Снова запусти Claude Code и повтори запрос чтения. Две записи для одного сервиса не нужны.

Для разбора нескольких страниц сначала попроси map показать их адреса, затем выбери нужные и ограничь crawl их числом. В варианте без ключа и без аккаунта полный набор недоступен: README оставляет только чтение страницы, поиск и обработку файлов. Поэтому для этой статьи используем авторизованное подключение.

Результат: виден вызов Firecrawl, а ответ содержит текст и пример с указанной страницы. Теперь осталось выяснить, подходит ли пример версии, с которой ты работаешь.

Шаг 4. Context7: найди документацию нужной версии

Даже официальный пример может относиться к другой версии программы. Context7 MCP приносит в чат документацию библиотек и примеры кода. Библиотека - готовый набор функций для разработки, который подключают к проекту. Context7 сначала находит её по названию, затем запрашивает нужные сведения из документации. Версию можно указать в запросе, как объясняется в README Context7.

Это как справочник с нужным изданием: название то же, но инструкции внутри могут отличаться. Context7 работает с доступными ему библиотеками, а не со всеми приложениями. Если точная версия не найдена, попроси сообщить об этом и перейти к её официальной документации. Авторы не гарантируют полноту и точность всех материалов.

Открой кабинет Context7, войди и создай ключ API. Выйди из Claude Code через /exit, затем вставь ключ вместо YOUR_API_KEY в терминале:

claude mcp add --scope user --header "Authorization: Bearer YOUR_API_KEY" --transport http context7 https://mcp.context7.com/mcp

Это ручное подключение из официальной справки для Claude Code; его адрес и заголовок также указаны в README. Снова запусти claude, открой /mcp и найди context7.

Для проверки возьмём ту же задачу с Next.js. Не нужно самому искать версию в файлах:

Через Context7 найди документацию Next.js App Router о создании новой страницы. Если в этой папке есть проект Next.js, сначала определи установленную версию по файлам зависимостей. Если такого проекта нет, возьми последний стабильный выпуск, проверь его через Perplexity. Укажи версию, выбранную библиотеку Context7, ссылку на документацию и пример создания страницы /about. Если документации именно этой версии нет, скажи об этом и не выдавай пример другой версии за подходящий.

Результат: видны вызовы Context7, в ответе названы библиотека, версия и источник примера. Если точная версия недоступна, это указано прямо. Все четыре подключения готовы к одной общей проверке.

Если подключение не заработало

Запись в списке означает, что настройка сохранена. Рабочий результат появляется только после вызова инструмента. Claude Code показывает Connected («Подключено»), Needs authentication («Нужен вход») или Failed to connect («Не удалось подключиться»).

Имя сервера уже существует

Не добавляй вторую запись. Запусти claude, открой /mcp, найди существующее подключение и выполни проверку из его шага. Если надо заменить адрес, удаляй только нужный сервер и в том же месте хранения, где он добавлен. Например, для нашего Firecrawl: claude mcp remove --scope user firecrawl. Затем повтори его установку. Команда удаления описана в справке Anthropic.

Ошибка 401 или 403

У Perplexity и Context7 проверь ключ в кабинете сервиса и пробел после Bearer в команде. Для замены неверного ключа удали только это подключение в его исходном scope («месте хранения»), добавь заново с новым ключом и перезапусти сеанс. У Firecrawl с входом через аккаунт повтори авторизацию в /mcp. Эти два способа доступа различаются, что объясняет справка Claude Code.

Лимит исчерпан или инструмент не вызывается

При сообщении о лимите открой кабинет соответствующего сервиса и проверь остаток. Если сервер подключён, а Claude Code отвечает без вызова, повтори запрос с явным «через Perplexity», «через Playwright», «через Firecrawl» или «через Context7». Попроси показать использованный инструмент. При ошибке запиши её точный текст без ключа и воспользуйся блоком помощи.

Шаг 5. Проверь четыре MCP на одной задаче

Теперь проверим исходную проблему: как получить инструкцию по созданию страницы в Next.js и увидеть, что она опирается на нужную версию. Этот тест не меняет файлы проекта. Он соединяет найденный источник, прочитанный текст, открытую страницу и пример из документации.

Если сейчас ты внутри Claude Code, закончи сеанс командой /exit. В терминале той же папки запусти новый сеанс командой claude и отправь один запрос:

Проверь все четыре MCP на одной задаче: как создать страницу /about в Next.js App Router. Файлы проекта пока не меняй.

1. Через Perplexity найди последний стабильный выпуск Next.js, дату и официальный источник. Если в папке есть проект Next.js, отдельно определи его установленную версию по файлам зависимостей и используй её для примера. Если проекта нет, используй найденную стабильную версию.
2. Через Firecrawl прочитай официальную страницу https://nextjs.org/docs/app/getting-started/layouts-and-pages. Покажи, к какой версии относится этот документ, если это указано, и какое объяснение создания страницы ты взял оттуда.
3. Через Playwright открой этот же адрес, покажи адрес после переходов, заголовок и сохрани скриншот в папке проекта. Формы не отправляй.
4. Через Context7 найди документацию выбранной версии Next.js и пример страницы /about. Сравни с прочитанным документом. Если документации точной версии нет или источники расходятся, назови ограничение и проверь официальный источник для нужной версии. Не подменяй её другой молча.

В конце покажи таблицу: MCP, какой инструмент вызван, результат, источник или файл. Дай короткую инструкцию для /about с версией и ссылкой на подходящий официальный документ. Если этап не выполнен, отметь его отдельно: не называй весь тест успешным.

Прочитай таблицу. У Perplexity должен быть свежий официальный источник, у Firecrawl - содержание выбранной страницы, у Playwright - открытый адрес и существующий скриншот, у Context7 - документация выбранной версии или явное сообщение о её отсутствии. Не выполнен один этап - вернись только к его проверке.

Результат: четыре сервера действительно вызваны, их ответы показаны, а инструкция для /about сопровождается версией и официальной ссылкой. Теперь у уверенного ответа Claude Code есть проверяемое основание: видно, откуда он взял сведения и к какой версии они относятся.
