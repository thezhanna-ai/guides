# Обложка: встроенный imagegen и типографика

Генерация: built-in image_gen, product-mockup, фотографическая сцена без надписей

Промпт: премиальная реалистичная предметная фотография. Широкий горизонтальный кадр 1,9:1. Стол и фон тёмная бирюза #102F30. Только справа металлический USB-хаб с четырьмя подключёнными плетёными кабелями; один коралловый #E86F4A, остальные светлые и тёмно-зелёные. Реалистичные материалы, боковой свет, глубокие тени. Левая половина пустая под текст, предметы строго после 55% ширины. Без надписей, логотипов, водяных знаков, иконок, схем, листов и интерфейсов

Типографика наложена отдельно по геометрии существующего oblozhka-layout.json: 1600×840, Unbounded 700 для заголовка, Spectral для вопроса, JetBrains Mono для метки и домена

Надписи: CLAUDE CODE; Четыре / MCP; Где взять свежие инструкции?; pronovoe.com

Сцена и финал сохранены в assets; геометрия и размеры текста в oblozhka-layout.json. Обложка открыта в полном размере и в превью 390 px, четыре кабеля видны, подзаголовок не заходит на предмет
