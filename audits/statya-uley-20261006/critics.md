# Последовательные критические проходы

Проверка выполнена автором работы в двух явно разделённых ролях, без независимых субагентов. Это редакционная вычитка, не пользовательский тест и не браузерная проверка. Финальная версия: claude-ai/uley-agentov-ruflo/index.html

## Круг 1: новичок без кода

Критерии: где вводить команду, что уже установлено, как различить подключение и запись, где увидеть полезный результат

- Недостающая ветка Pending approval: .mcp.json может требовать одобрения, а шаг 2 просил сначала добиться Connected. Исправление: запустить claude, одобрить проектный сервер, выйти и повторить список. Строка расположена перед запасной командой добавления сервера
- Команда init по умолчанию добавляет указатель в общие инструкции Claude Code. Исправление: --no-global с объяснением, подтверждённым init --help и init.ts
- Роль, зарегистрированная в Ruflo, не равна исполнителю. Исправление маршрута: запрос требует реальные задания двум разным субагентам Claude Code и запрещает считать регистрации выполнением работы
- Пустой поиск памяти не отвечает на вопрос о конкретной записи. Исправление маршрута: точный ключ и единый namespace, успешное чтение перед передачей задачи, остановка при ошибке памяти

## Круг 1: структура

Критерии: пять вопросов раздела 2а, обещание задания, нарастание, факты и первоисточники, оболочка, пересечения с опубликованными статьями

- Кнопки образца зелёные, ТЗ требует коралловые. Исправление: #E86F4A у кнопок в плашках, добавлены hover/active/copied и постоянная ширина для подписи успеха. Логика JavaScript сохранена побайтно
- У копированного абзаца CTA не было завершающей точки. Исправлено по правилам статьи
- Два якоря справки не соответствовали актуальным названиям разделов. Исправлены managing-your-servers и choose-between-subagents-and-main-conversation; факт переименования привязан к CHANGELOG
- В первой фразе была боль, но вопрос появлялся только третьим предложением. Исправление: вопрос о раздаче работы и сохранении контекста открывается первой фразой

## Круг 2: новичок без кода

Прочитана изменённая страница от подготовки до нового чата. Для всех пяти шагов названы место действия и наблюдаемый результат. Подготовка включает три версии и ветку отсутствующей команды. Pending approval разрешается до требования Connected. Учебный результат открывается двойным щелчком; названы оба показания счётчика. Финальная проверка запрещает подменять память чтением файла

## Круг 2: структура

Маршрут нарастает: настройка -> подключение -> успешный вызов -> страница с отдельной проверкой -> восстановление требований и результата в новом чате.
