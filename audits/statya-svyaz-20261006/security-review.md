# Проверка перед коммитом

- Изменения: новая статическая статья, изображения, запись draft в statyi.json, документация проверки, два фиксированных количества проверяемых HTML-страниц в существующих тестах
- Нового исполняемого кода приложения нет. JavaScript оболочки перенесён из живой статьи без изменения логики, внешних скриптов не добавлено
- В HTML не обнаружены ключи, токены, реальные адреса почты читателя или данные переписки. Тестовый адрес берётся у самого читателя в его чате, не подставляется автором
- MCP-адрес опубликован Composio и использует HTTPS. Ссылки ведут на официальные домены сервисов или существующие статьи
- Промпт создания черновика разрешает только один новый черновик, запрещает отправку и изменения существующей почты. Читателю предложено сверить действие перед подтверждением
- В статье объяснены права, отключение ChatGPT и отдельное управление доступом Composio в Google
- Обложка сгенерирована по предметному описанию без пользовательских файлов, почты и бизнес-данных. Только фотографическая сцена, скриншоты не генерировались
- Реестр выдачи собран из этой ветки в audit. Общий live-реестр, Desktop, main и другие worktree не изменялись
- Черновик не включён в главную и sitemap, выдача net, robots noindex, nofollow
- Проверка синтаксиса всех встроенных JavaScript входит в полный прогон Python; проверка diff и состава коммита выполнена перед записью коммита
