# Security-review: политика и согласие

Дата: 06.10.2026. Самостоятельное последовательное ревью, без браузеров. Проверены diff генератора/тестов и полный новый JS/CSS, HTML-фрагмент и шаблон политики

## Проверенные свойства

- Загрузчик существует только в локальном assets/privacy.js; источник библиотеки фиксирован: https://mc.yandex.ru/metrika/tag.js. Данные посетителя и localStorage не подставляются в URL, HTML или eval
- METRIKA_ID пустой, а при настройке допустим только положительный безопасный целый номер. Нет загрузки при пустом/невалидном ID даже после согласия
- HTML содержит только локальный script defer. Пикселей noscript, preconnect/prefetch/DNS hints к Метрике и иных внешних сетевых элементов нет
- Только значение accepted означает согласие. Ошибки чтения/неизвестные значения хранилища не разрешают загрузку
- Обработчик загрузки повторно проверяет выбор: позднее завершение загрузки после отказа не инициализирует счётчик
- Отказ сохранён, отзыв вызывает destruct и перезагрузку; изменение/очистка согласия в другой вкладке прекращает работу счётчика
- Отказ и согласие имеют равнозначные кнопки, настройки доступны из подвала; доступ к чтению не ограничен
- Вебвизор, карта кликов и Яндекс Тег Менеджер выключены; формы и UserID/userParams не добавлены
- В новой публичной политике только разрешённый email. ИНН, домашний адрес, телефон и паспорт отсутствуют. Частная инструкция РКН находится в IvanOS вне публичного репозитория сайта
- Генератор сохраняет существующую проверку slug/path; при отсутствующем подвале создаёт один, а при неоднозначной структуре прекращает сборку. Общие блоки заменяются по меткам, повторная сборка идентична
- Нормализация исходных 39 страниц после удаления добавленных блоков совпала с исходным ed2892d: статья, CTA, поисковый код и прежние юридические исправления сохранены
- Поиск по новым публичным исходникам на private-key, типичные API/GitHub токены и частные реквизиты: совпадений нет. Значения потенциальных секретов в вывод не печатались
- main и origin/main сверены с начальными SHA и не изменены

## Практические границы

Node VM перехватывает назначение src загрузчика и не делает реальную сеть. Python проверяет все HTML-точки подключения; захват трафика браузера и визуальный осмотр при 390 px не проводились по прямому запрету задания. CSS резервирует измеренную высоту плашки для прокрутки конца страницы, переносит мобильные элементы и учитывает safe-area; это не результат скриншотной проверки

При недоступном localStorage выбор действует в текущем документе. При отзыве уже переданные данные автоматически не уничтожаются: политика направляет к оператору для запроса удаления. Обработку/сроки у внешних провайдеров и адреса баз необходимо подтвердить отдельно, номер счётчика остаётся пустым
