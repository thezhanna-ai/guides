Перед настройкой

Нужен Claude Code, который запускается командой claude и отвечает после входа. Если есть только расширение в VS Code, проверь и терминальную команду: она устанавливается отдельно. Начать можно с инструкции по установке Claude Code. Доступ к моделям работает по условиям твоего аккаунта, Ruflo его не заменяет.

Также нужен Node.js версии 20 или выше и npm версии 9 или выше. Это требования Ruflo. Скачай Node.js с пометкой LTS («с долгой поддержкой») с официального сайта. Вместе с ним устанавливается npm, а npx позволяет запустить нужный пакет без отдельной глобальной установки.

Для первого опыта создай пустую папку ruflo-test и открой её в VS Code через File → Open Folder («Файл → Открыть папку»). Дальше выбери Terminal → New Terminal («Терминал → Новый терминал»). Терминал - нижняя панель, куда вводятся команды. Запускай их из этой папки, каждую отдельно, нажимая Enter:

node --version
Скопировать

npm --version
Скопировать

claude --version
Скопировать

Первые две команды должны вывести версии не ниже указанных, третья - версию Claude Code. Если видишь command not found («команда не найдена»), установи соответствующую программу, закрой терминал и открой новый. До появления трёх версий к настройке Ruflo не переходи.

Дальше подпись «В терминале» означает обычное окно команд. Подпись «В чат Claude Code» означает поле сообщения после запуска claude. Если уже находишься в этом чате, команда /exit возвращает в обычный терминал.

Шаг 1. Подготовь Ruflo одной командой

В свежем README есть путь через плагины Claude Code и путь через терминальную программу. Здесь используем второй: он даёт прямое подключение MCP и проектную память для нашей проверки. На 8 октября актуальный выпуск npm - 3.55.0, его номер закреплён в команде инициализации и ручного подключения ниже.

В терминале папки ruflo-test запусти короткую инициализацию:

npx -y ruflo@3.55.0 init --no-global --no-mods --no-codex-detect --no-skills-sh --no-signup
Скопировать

-y подтверждает загрузку пакета Ruflo. Остальные флаги оставляют настройку для нашего проекта: --no-global отключает указатель в общих инструкциях, --no-mods - установку дополнительных модов, --no-codex-detect - автоматическую настройку Codex, --no-skills-sh и --no-signup - дополнительные установку скилла и предложение регистрации. Их назначение описано в команде init и проверено в справке выпуска 3.55.0. Дождись сообщения об успешном завершении.

Инициализация создаёт инструкции для Claude Code и служебные папки проекта. Среди них - CLAUDE.md с правилами работы и .claude-flow/ с настройками. Папки с точкой могут быть скрыты в файловом менеджере. Команда готовит инструменты; конкретная работа начнётся, когда ты отправишь задачу.

Открой .mcp.json в VS Code: инициализация создаёт сервер claude-flow с пакетом ruflo@latest. Это запуск актуального выпуска на момент обращения. Ручная команда в следующем шаге закреплена на 3.55.0 и нужна только при отсутствии записи.

Результат: команда завершилась без ошибки, а в папке проекта появился CLAUDE.md с упоминанием Ruflo или Claude Flow. Дальше проверим, что Claude Code может обращаться к его инструментам.

Шаг 2. Проверь подключение MCP

MCP - способ подключить дополнительные инструменты к Claude Code. Через него Ruflo даёт доступ к координации и общей памяти. В терминале той же папки введи:

claude mcp list
Скопировать

Найди подключение claude-flow или ruflo и проверь, что рядом успешное соединение: Connected («Подключено»). Имя claude-flow осталось в команде текущего README, хотя пакет называется ruflo. Если уже установлен плагин Ruflo, сначала проверь его сервер: второе подключение к той же памяти не добавляй.

Если вместо соединения видишь Pending approval («Ожидает одобрения»), запусти claude из этой папки и одобри проектный сервер Ruflo, который только что настроили. Затем выйди через /exit и повтори claude mcp list. Так Claude Code разрешает подключения из настроек проекта.

Если ни одного из этих подключений нет, добавь сервер командой ниже и снова выполни claude mcp list. Флаг -y разрешает npx загрузить пакет без вопроса, на который фоновый сервер не сможет ответить:

claude mcp add claude-flow -- npx -y ruflo@3.55.0 mcp start
Скопировать

Если подключение уже есть, но не работает, второй сервер не добавляй. Причину разбираем в блоке «Если не получилось». Проверка списка серверов и команда /mcp описаны в справке Claude Code.

Результат: в списке есть Ruflo и подтверждено соединение. Одной записи с названием сервера недостаточно.

Шаг 4. Собери страницу силами команды

Учебная задача этой статьи - страница с чек-листом подготовки короткого видео, которую можно открыть в браузере. Для неё не нужны внешние сервисы. Claude Code будет координатором, отдельный исполнитель напишет код, а проверяющий прочитает его и вернёт замечания.

Ruflo координирует работу, а Claude Code выполняет её. Вызов agent_spawn («зарегистрировать роль агента») сам по себе не доказывает, что отдельный исполнитель написал код. Для выполнения нужны субагенты Claude Code - отдельные помощники со своим заданием и контекстом.

Для памяти нужны два инструмента: memory_store («записать») сохраняет значение под ключом, memory_retrieve («прочитать») возвращает его по ключу и пространству имён. Пространство имён - группа записей одной задачи. Этот интерфейс доступен в MCP выпуска 3.55.0.

Сколько стоит

Сверка: 8 октября 2026 года, суммы в долларах США. Для выбранного маршрута нужна локальная программа Ruflo и доступ к Claude Code.

Ruflo: $0 за пакет. Он распространяется по лицензии MIT. У установки через npm и локального MCP-сервера нет отдельной месячной подписки. Хранилище этой проверки находится в папке проекта на твоём компьютере.

Claude Code: Pro стоит $20 в месяц при помесячном расчёте или $200 за год. На странице годового тарифа месячный эквивалент округлён до $17. Max начинается со $100 в месяц. Claude Code входит в эти тарифы, а лимиты использования зависят от выбранного плана.

Субагенты: отдельного тарифа Ruflo за каждую роль нет. Их запросы учитываются в тех же лимитах Claude Code, что и работа координатора. Если Claude Code подключён через API, расход идёт по тарифам выбранной модели за входной и выходной текст, а не по фиксированной цене команды.

Для учебной страницы не нужны внешние API, облачные сервисы Ruflo и дополнительные ключи. При уже доступном Claude Code можно начать с локального пакета за $0. Команда агентов расходует запросы модели: число ролей не даёт гарантии экономии.
