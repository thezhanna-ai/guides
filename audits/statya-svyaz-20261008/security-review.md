# Security review перед коммитом

HTML, реестр, снимки и проверки: новых исполняемых зависимостей на сайте нет. CSS и функциональные скрипты перенесены из свежего ШТАТ; изменена только подпись кнопки просмотра на «Увеличить». Приватные письма не читались, авторизация не выполнялась. В публичных JPG размыты инициалы на трёх экранах. Запрос черновика запрещает отправку; OAuth-права и тарифные ограничения названы явно. ERID, партнёрская ссылка и локальная политика сохраняются. Общие стили и другие статьи не изменены
