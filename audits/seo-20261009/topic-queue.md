# Очередь новых тем со спросом

Срез 08.10.2026

**Допущенных тем: 0**

Wordstat не предоставил частоты в доступной среде. По правилу SEO-движка тема без измеренного спроса не допускается в производство. Список из десяти гипотез вынесен отдельно в audits/seo-20261009/topics-to-measure.md; он не является очередью публикаций

После замера для каждой темы записать: запрос, регион, период, широкий спрос и точную частоту в кавычках, источник/экспорт с датой, интент, владельца URL или новую страницу. Отсеять дубли реестра. Порог допуска взять из настроек движка после согласования региона, а не назначать произвольно
