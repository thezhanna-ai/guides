## Пересечения и владельцы интентов

1. `podklyuchenie-iz-rossii` владеет первым подключением нового аккаунта, `claude-iz-rossii-bez-banov` - восстановлением доступа к существующему, `svoy-server-dlya-claude` - сервером, личным VPN и удалённой работой. Для общего запроса «Claude из России» оставить владельцем первую страницу; две остальные удерживать на своих уточняющих запросах. Не сливать: шаги и результат различаются
2. `pyat-skillov-claude-code` владеет установкой и проверкой конкретного набора в Claude Code. `shest-skillov` - подключением и вызовом шести Claude Skills с примерами применения, `pyat-instrumentov-claude-code` - выбором дополнений под проблему (включая маршрутизатор и отчёты). Для общей установки скиллов Claude Code оставить владельцем `pyat-skillov-claude-code`. Самое заметное потенциальное пересечение: claude-mem; точный конфликт ранжирования без Search Console/Вебмастера не доказан
3. `pervyy-proekt-v-claude` - общая база проекта; `kak-rasskazat-o-sebe` - личная память и настройки; `svoy-stil-otvetov` - свой голос ответов. Разные цели, сохраняются отдельно
4. `dannye-v-claude` - удаление данных, `incognito-chat-v-claude` - разовый разговор, `otozvat-ssylku-na-chat-claude` - уже опубликованная ссылка. Для запроса об удалении данных оставить `dannye-v-claude`; остальные не обещают удалить все данные
5. Семь подборок промптов делят формулировку «промпты ChatGPT». Владельцы уточняющих интентов: свет, товар, блог, игрушки, рисунок, ретро, еда. Общую частотную формулировку не назначать всем семи. `kopirovat-stil-foto-v-chatgpt` - перенос стиля через JSON, `postery-iz-odnogo-foto` - конкретный постер. Сохраняются отдельно
6. `besplatnye-video-iz-teksta` - выбор генератора; `montazh-video-claude-code-codex` - монтаж исходников; `animirovannaya-karusel` - продолжение движения между слайдами; `ozhivit-maket-bez-keyframe` - анимация Figma. Объединение уничтожило бы разные инструкции
