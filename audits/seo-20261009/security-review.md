# Security-review перед коммитом

Чтением проверены scripts/sobrat_glavnuyu.py, scripts/indexnow.py, tests/test_seo.py и HTML-diff относительно 3c60841

- Метаданные и вопросы экранируются html.escape; JSON-LD дополнительно экранирует <, >, &, чтобы содержимое не закрывало script. Отрицательная проверка </script> проходит
- Генератор не выполняет строки метаданных как команды, не добавляет внешние скрипты, счётчики или сетевые запросы. Тематические ссылки допускают только /claude-ai/<slug>/; подписи экранируются
- IndexNow не отправляет данные при обычном запуске. Host, публичный verification key, keyLocation и полный список URL проверяются до сети. HTML и ключ должны совпасть с опубликованными. Тесты старой публикации, чужого URL и правильной публикации прошли; POST в этой сессии не выполнялся
- Исходные рекламные блоки, цены и проза сохранены. Все изображения с src имеют alt и размеры, картинки не перезаписаны. Это подтверждено static-check.json, не оценкой модели
- Gitleaks v8.30.1: первый проход нашёл 2 экземпляра публичного IndexNow verification token и временный captcha-параметр в неопубликованной оболочке Яндекса. Создан узкий allowlist конкретного публичного ключа и исключён только сырой captcha-cache, который также исключён из Git. Повторный проход: no leaks found (gitleaks.txt). Доступ к API-аккаунтам этот публичный токен не даёт
- Аутентификации, админки, БД и нового пользовательского ввода нет. Новые пути сетевого взаимодействия ограничены явным CLI --send на официальном endpoint IndexNow. Браузерные UI-проверки недоступны, вердикт их не включает

Статический security-review пройден. Приёмка по скорости и скриншотам остаётся заблокирована отдельно
